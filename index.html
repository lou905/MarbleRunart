AP CSP · Cardboard Marble Run · Worked example

Build a zig-zag with a loop and a procedure

The box runs from x = −55 to 55 and from y = 0 (floor) to 80 (top). Every ramp you place is one line of code. A loop lets one block of code place many ramps.

ramp(x1, y1, x2, y2)wall(x, y_bottom, y_top)

The program

1def ramp_pair(y, drop):
2    ramp(-54, y, 48, y - drop)
3    ramp(54, y - drop - 5, -48, y - 2*drop - 5)
4
5y = 74
6for i in range(3):
7    ramp_pair(y, 5)
8    y = y - 20
9
10ramp(-54, y, 30, y - 6)  # last ramp

10 lines of code place 7 pieces of cardboard. Without the loop and the procedure, you would type 7 separate ramp() lines.

Where the AP CSP ideas show up

  • SequenceLines run top to bottom, so ramps are placed from the top of the box down.
  • Iterationfor i in range(3) repeats lines 7–8 three times.
  • Variablesy remembers the current height and drops by 20 each pass.
  • Procedureramp_pair bundles two ramps under one name, with parameters y and drop.
  • AbstractionLine 7 says "make a pair" without caring how the pair is built.

Same idea in AP exam pseudocode

PROCEDURE rampPair(y, drop)
{
   ramp(-54, y, 48, y - drop)
   ramp(54, y - drop - 5, -48, y - 2 * drop - 5)
}
y ← 74
REPEAT 3 TIMES
{
   rampPair(y, 5)
   y ← y - 20
}

Think about it

  1. What would y be after the loop if it were range(4)? Would the last ramp still fit in the box?
  2. Change drop from 5 to 3. Do the ramps get steeper or flatter? Will the marble go faster or slower?
  3. Which single number would you change to add more ramps without changing the spacing?
  4. Why do ramp A and ramp B stop at 48 and −48 instead of touching the wall?
  5. Type this into the site and run it. Where does the marble land? What would you change to hit the cup?

Answers to 1–4: y = −6 (the last ramp would go below the floor, so no) · flatter, slower · the 3 in range(3) along with the 20 gap · the gap lets the marble fall to the next ramp.
